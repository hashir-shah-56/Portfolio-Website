Case Study

Shah Embroidery & Art

A responsive e-commerce platform for a real handmade embroidery and artwork business.

HTML5 CSS3 JavaScript Supabase Git / GitHub Netlify

Project Overview

Shah Embroidery & Art is a fully functional e-commerce website built for a handmade embroidery and artwork business. The goal was to create a polished online presence where customers can browse products, place orders, and manage their accounts — and where the business owner can manage inventory through a secure admin dashboard.

My Role

I was the sole developer responsible for the entire project — from planning and design to frontend implementation, Supabase backend integration, and deployment on Netlify.

Key Features

  • Dynamic product catalog with search and category filtering
  • Customer authentication — sign up, login, and account management
  • Shopping cart and wishlist functionality
  • Custom-order request flow
  • Checkout process
  • Owner-only admin dashboard for product and order management
  • Supabase integration for database, auth, and storage
  • Fully responsive across all device sizes

Development Approach

Built with plain HTML, CSS, and vanilla JavaScript — no frameworks — keeping the codebase simple and maintainable. Supabase handled authentication, real-time database queries, and asset storage. The project was version-controlled with Git and deployed to Netlify.

Challenges & Solutions

  • Implementing row-level security in Supabase to restrict admin routes to the owner only
  • Building a cart and wishlist system with persistent state across sessions
  • Ensuring the layout remained polished across mobile, tablet, and desktop breakpoints
  • Managing product image storage and retrieval efficiently through Supabase Storage
