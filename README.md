## 📌 About

This portfolio was created to build my professional online presence and demonstrate my front-end development skills through a real-world project.

The design follows a **dark, edgy aesthetic** with neon-green accents, glassmorphism elements, modern typography, and responsive layouts.

The website is designed to provide a clean experience across desktop, tablet, and mobile devices.
